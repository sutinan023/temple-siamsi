# วิหารเซียมซี — Temple Fortune Walk

ต้นแบบเว็บ 3D ด้วย Next.js (JavaScript JSX) + Three.js สร้างฉากวัดไทยแบบ procedural ไม่ต้องโหลดโมเดลหรือไฟล์ภาพภายนอก

## วิธีรัน
1. ติดตั้ง Node.js เวอร์ชัน 20 ขึ้นไป
2. แตก ZIP แล้วเปิดโฟลเดอร์ `temple-siamsi-3d` ใน VS Code
3. เปิด Terminal และใช้คำสั่ง:

```bash
npm install
npm run dev
```

4. เข้า http://localhost:3000

## วิธีเล่น
- กด **เข้าสู่วิหาร**
- ใช้ **W A S D** หรือ **ปุ่มลูกศร** เดินบนทางหิน และลากเมาส์/นิ้วเพื่อหมุนมุมมอง
- มือถือมีปุ่มเดิน 4 ทิศบนหน้าจอ (กดค้าง)
- เดินเข้าไปใกล้โต๊ะบูชาหน้าศาลา จะมีปุ่ม **เสี่ยงเซียมซี** หรือกด **E**
- เขย่ากระบอก 3 ครั้ง แล้วเปิดคำทำนายแบบสุ่ม 1 จาก 12 ใบ
- กดบันทึก/พิมพ์ใบเซียมซี หรือเดินกลับไปสำรวจ

## โครงสร้าง
- `app/page.jsx` — Three.js scene + UI + ตัวสุ่มคำทำนาย
- `app/globals.css` — Styles, animation, responsive layout
- `app/layout.jsx` — Root layout / metadata

## หมายเหตุ
- ออกแบบเป็นต้นแบบเชิงศิลป์ ไม่ได้จำลองวัดจริงแห่งใด
- ข้อความเซียมซีสร้างขึ้นเพื่อความบันเทิงและการใคร่ครวญ ไม่ใช่คำทำนายจริง
- Audio ปิดเป็นค่าเริ่มต้น กดเปิดก่อนจึงเล่นเสียงระฆังเมื่อได้ใบเซียมซี
- ควรเพิ่มระบบภาพและเสียงที่มีลิขสิทธิ์ถูกต้องสำหรับเวอร์ชันใช้งานจริง

## Build / Deploy
```bash
npm run build
```
