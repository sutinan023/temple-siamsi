# Temple Fortune Walk V03.2

ปรับปรุงจากไฟล์ `page(2).jsx` ที่ผู้ใช้ส่งมาโดยตรง และคง CSS / UI / พิธีเซียมซี 12 ใบเดิม

## Changes
- ปรับมุมเริ่มต้นและลดหมอกให้มองเห็นวิหารระยะไกลชัดขึ้น
- เพิ่มกระเบื้องหลังคาแบบ InstancedMesh, ลายหน้าบันและเส้นตกแต่งทอง
- เพิ่มหลังคาทรงไทยให้ซุ้มประตู
- เพิ่มใบไม้ขนาดเล็กแบบ InstancedMesh เพื่อให้ทรงพุ่มมีรายละเอียดขึ้น
- เดินแบบมีความเร่ง/ลดความเร็ว และตรวจชนเสาประตูและโคมไฟ
- คง UI เดิม ระบบเสี่ยงเซียมซีและเสียงเดิม

**ข้อจำกัด**: ยังเป็นฉากที่สร้างด้วยเรขาคณิต Three.js และ Texture procedural ไม่ใช่โมเดล GLB ของวัดจริง และยังไม่ใช่ภาพระดับ photorealistic

## Setup
```bash
npm install
npm run dev
```

ตรวจด้วย TypeScript JSX parser (syntax) แต่ไม่ได้ตรวจการเรนเดอร์จริงในเบราว์เซอร์ในสภาพแวดล้อมนี้
