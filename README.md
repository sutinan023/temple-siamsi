# วิหารเซียมซี — Temple Walk V03.1

เว็บเดินเข้าวัดและเสี่ยงเซียมซี (Next.js + Three.js) — อัปเกรดภาพจาก V02 โดยไม่เปลี่ยนระบบเดินและคำทำนาย

## สิ่งที่เปลี่ยนใน V03.1

- วิหารหลังคาลาด 3 ชั้น, หน้าบันประดับเส้นทอง, ขอบหลังคา, กรอบช่องเปิด, ประตูทางเข้า
- ทางเดินเพิ่มแผ่นหินและรอยต่อแยกชิ้น
- ต้นไม้มีลำต้น กิ่ง และพุ่มใบหลายก้อน (แทนต้นไม้ทรงกลมแบบเดิม)
- วัสดุไม้ พื้น และหลังคาใช้ procedural CanvasTexture พร้อมปรับ roughness / metalness
- ปรับบรรยากาศแสงอุ่นและหมอกระยะไกล
- คงระบบ WASD, ปุ่มมือถือ, มองด้วยการลาก, เสียงเปิด/ปิด, พิธีเขย่า 3 ครั้ง และคำทำนาย 12 ใบ
- เพิ่ม .gitignore ป้องกัน node_modules/.next ถูกอัปโหลดเข้า Git

> ข้อจำกัด: V03.1 ยังเป็น **procedural 3D** ไม่ใช่โมเดล photorealistic GLB และยังไม่มี photogrammetry หรือ HDRI ภายนอก เป้าหมายของระยะนี้คือปรับองค์ประกอบและวัสดุให้ดูมีรายละเอียดมากกว่า V02. หากต้องการสมจริงมากขึ้นอีก ขั้นถัดไปคือใส่โมเดล GLB สถาปัตยกรรมวัดที่มีแหล่งที่มาและสิทธิ์การใช้ชัดเจน

## ติดตั้ง / รัน

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

## อัปเดตโปรเจกต์ V02 ในเครื่อง

1. สำรองไฟล์เดิมก่อน (`git commit` หรือ copy ทั้งโฟลเดอร์)
2. คัดลอก `app/page.jsx` และ `.gitignore` จาก ZIP นี้ไปทับใน root โปรเจกต์ V02 (ไม่ต้องย้าย node_modules)
3. รัน `npm run dev`
4. ตรวจหน้าจอเดินและใบเซียมซี แล้วตรวจ `git status` ก่อน commit

## การควบคุม

- `W A S D` หรือปุ่มลูกศร: เดิน
- ลากเมาส์ / นิ้วบนภาพ: มองรอบตัว
- `E` เมื่อถึงบริเวณโต๊ะบูชา: เริ่มเสี่ยงเซียมซี
- เปิดเสียงด้วยปุ่มมุมขวาบน

## หมายเหตุด้านคุณภาพ

โค้ดผ่านการตรวจไวยากรณ์ JSX แล้ว แต่ยังไม่ผ่าน production build ในสภาพแวดล้อมนี้ (การดาวน์โหลด dependencies ใช้เวลาเกินกำหนด) จึงควรทดสอบ `npm run build` บนเครื่องก่อน deploy.
