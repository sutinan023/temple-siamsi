# วิหารเซียมซี — V02 (3D Temple Walk)

เว็บจำลองบรรยากาศเดินเข้าวัดไทยและเสี่ยงเซียมซี พัฒนาด้วย Next.js + Three.js โดยไม่ใช้โมเดล/เสียงจากแหล่งภายนอก

## ติดตั้งและทดสอบ

ต้องใช้ Node.js 20 ขึ้นไป

```bash
npm install
npm run dev
```

เปิด http://localhost:3000

```bash
npm run build
npm run start
```

## วิธีเล่น

1. คลิก **เข้าสู่วิหาร**
2. เดินด้วย **WASD / ลูกศร** หรือปุ่มลูกศรบนจอมือถือ
3. ลากเมาส์ / ปัดบนฉากเพื่อหันมอง; เดินตามทางหินเข้าสู่ศาลา
4. เปิดเสียงบรรยากาศที่มุมบนขวา (เริ่มปิดเป็นค่าเริ่มต้น)
5. ถึงบริเวณแท่นเซียมซี กด **E** หรือปุ่ม **เสี่ยงเซียมซี**
6. เขย่ากระบอก 3 ครั้งแล้วอ่านใบคำทำนาย (จำลอง)

## V02 เพิ่มจาก Prototype 01

- ปรับโทนภาพและแสงแบบ golden hour พร้อมหมอกระยะไกลและ soft shadow
- เพิ่มหน้าจั่วทรงไทยบนหลังคาวิหารและรายละเอียดทอง
- เพิ่มสระบัวสองฝั่ง ทางเดินกรวด พุ่มไม้ ภูเขาไกล ๆ และผีเสื้อเคลื่อนไหว
- เพิ่มระบบเสียงบรรยากาศลมและระฆังแบบสังเคราะห์ผ่าน Web Audio (ไม่ต้องดาวน์โหลด asset)
- ปรับข้อความนำทางและ intro ให้ตรงกับธีมวัดไทย
- รักษา flow และระบบสุ่มเซียมซี 12 ใบจาก V01

## หมายเหตุ

ภาพวัดสร้างจาก geometry แบบ procedural ยังไม่ใช่ photorealistic model หรือวัดจริงใด ๆ คำทำนายจัดทำขึ้นเพื่อความบันเทิง/การใคร่ครวญ ไม่อ้างอิงผลจริง
